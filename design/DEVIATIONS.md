# Deviations from the design

Every place the shipped code differs from `design/assets/*.html` or `design/DESIGN.md`, with the reason and
the authority. Anything not listed is expected to match within the parity thresholds in
`docs/decisions.md` §9.

> **The spec was replaced mid-`init` (2026-09-20).** The original DESIGN.md described a different theme
> ("Cinematic Dark", `#000000` + racing red `#e10600`) from the one every artboard exports
> ("Track Night", `#0B0B0D` + acid lime `#C9F23A`). The replacement documents Track Night directly, which
> dissolved six of the seven colour-related deviations logged earlier. The superseded file is kept at
> `design/DESIGN.superseded-cinematic-red.md` for audit — there was no git history when it was replaced
> (D3), and the initial commit (D55) holds only the post-swap tree.

## Resolved by the spec update — no longer deviations

Palette · card hover border (`--accent-hover`) · quote-first commerce with no cart · "tire" not "tyre" ·
nav height 88/68 · page padding 48/16 · PDP 55/45 split · input height 56 · card body padding 24/14 ·
card image 6% inset · badge inset 16/10 · card price 28/24 · the mobile PDP sticky bar (the new §8 drops
it, matching the artboard) · `--winter`/`--all-season` (now given a defined role in §2 and ported).

The **one-accent rule** also changed materially: it is now "judge by the frame, not the component —
in an otherwise quiet grid the badge and CTA are far enough apart to coexist." The artboards' badge+CTA
cards are compliant under that wording, so this is no longer a conflict and nothing needs demoting.
