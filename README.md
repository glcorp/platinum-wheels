# Platinum Wheels

Quote-first storefront for Platinum Wheels and Tire Solutions, Brampton, Ontario.
Next.js 16.4 canary · React 19.3 · TypeScript strict · Tailwind v4.

**Start here: [`llm.md`](llm.md).** It is the project library — purpose, rules, decisions and
connections for every folder. Each folder has its own `llm.md`. Read them before editing.

```bash
npm run check    # tsc + eslint — must be clean
npm run dev      # app on :3000
npm run design   # artboard baseline on :4000
```

`http://localhost:3000/styleguide` shows every primitive, variant and state.

Git repository since 2026-09-21 (D55) — `main`, private at `github.com/glcorp/platinum-wheels`.
Everything before that date is one initial commit, and the docs are its history.
